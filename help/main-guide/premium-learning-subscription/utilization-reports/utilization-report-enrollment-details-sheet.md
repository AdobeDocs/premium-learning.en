# Understanding Your Enrollment Details Sheet

## What does the Enrollment Details sheet show?
 
The Enrollment Details sheet provides the detailed data behind the Summary sheet. It includes learner information, course details, progress, attendance, completion status, and key enrollment and class dates.

A quick reference for reading the "Enrollment Details" tab of your Learning Utilization Report. This sheet is the data behind the Summary sheet — one row per learner enrollment.

- **Learner / Email** — Who the enrollment belongs to.
- **Modality** — Format of the training: Standalone ILT (live instructor course), Cohort (multi-session program), or Self-Paced/On-Demand.
- **Format** — How it's delivered, e.g. Virtual Classroom or Self Paced.
- **Product(s)** — Which Adobe product(s) the course covers. A course can list more than one.
- **Course / Training** — The specific course title.
- **Instance / Session** — The specific class run/session the learner is enrolled in (or "Default Instance" for self-paced content, which has no scheduled session).
- **Status** — Where the learner is in that course: Completed, In Progress, or Not Started.
- **Progress** — Decimal completion progress (1 = 100% complete, 0 = not started, values in between for partial).
- **Time Spent (min)** — Minutes the learner has logged in the course.
- **Enrollment Date** — When the learner was enrolled.
- **Started** — When the learner began the course (blank if not started).
- **Deadline** — Target completion date, if one is set.
- **Completed** — Date/time the learner finished, if they did.
- **Overdue** — Flag for whether the deadline has passed without completion.
- **Class Delivery Status** — Whether the class itself has run yet: Delivered, Scheduled, or In Progress. Only applies to ILT/Cohort; blank for self-paced.
- **ILT/Cohort Attendance** — Did the learner show up to the live session: Attended, Attended Partial, No Show, Scheduled, or In Progress. Only applies to ILT/Cohort.
- **Class Start / Class End** — Scheduled dates for the live session.
- **Month-Year** — The month the class/session falls in. This is what feeds the "Enrollment Trends by Month" table on the Summary sheet.
- **Timezone** — Timezone the class was run in.

## A few things to note

- Each row = one course enrollment, not one learner. A learner with 3 courses appears 3 times.
- Self-paced rows will always show blanks for Class Delivery Status, Attendance, Class Start/End, and Timezone — those columns only apply to live sessions.
