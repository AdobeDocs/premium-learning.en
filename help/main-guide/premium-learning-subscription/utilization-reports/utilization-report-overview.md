# Utilization Report Overview

Learn about utilization reports for your Premium Learning Subscription, including the learning activity they cover, who can request them, how much historical data they include, and why the current reports differ from previous reports.


## What is a utilization report?

A utilization report provides an organization-wide view of learning activity, including enrollments, course completions, attendance, certifications, and overall training usage.

## Who receives the utilization report?

The utilization report is available upon request to your organization's Enterprise point of contact (POC), who manages or oversees your Premium Learning Subscription. Individual learners do not receive this report.

## How much historical data is included in each monthly report?

Each monthly report is cumulative and includes all available data beginning in June 2026. Every future report will build on the previous one, so you can view historical and current learning activity in a single report. June 2026 marks the transition to the current learning platform, so data from the earlier platform is not included in these reports.

## Why doesn't the report include data from before June 2026?

The monthly utilization report includes data from the current learning platform, beginning in June 2026. Historical data from the legacy platform is available in a separate report. Enterprise points of contact can request a copy by [contacting us](https://adobe.service-now.com/adls?category=10).

## Why does the new utilization report look different from previous reports?

The new utilization report is generated from our current learning platform, which uses a different data model than the legacy platform. As a result, some fields and data points have changed.

The updated report also includes additional insights that were not available previously, such as more detailed completion information and visibility into learner no-shows, giving you a more comprehensive view of your organization's learning activity.
