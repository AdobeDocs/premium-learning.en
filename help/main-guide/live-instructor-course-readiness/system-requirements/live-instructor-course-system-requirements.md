# Live instructor course system requirements

## Be ready with Adobe Connect

Live sessions will be conducted using Adobe Connect. Ensure you follow these checkpoints to help avoid technical issues during the live session:

1. Run this [diagnostic test](https://training.adobeconnect.com/common/help/en/support/meeting_test.htm) to ensure that Adobe Connect is working properly on your system.
1. Go over the [technical specifications](https://helpx.adobe.com/adobe-connect/connect-tech-spec/12-10-technical-specifications.html) for Adobe Connect.
1. You can join Adobe Connect through a browser or the desktop application. If the desktop app is already installed and you are facing issues, uninstall the Adobe Connect application and reinstall it using the latest version provided [here](https://helpx.adobe.com/in/adobe-connect/connect-downloads-updates.html).

You'll find your personalized virtual meeting room link in your calendar invite. On the day of training, we recommend launching the link 5-10 minutes before class starts.

Additional Resources:

* [Help Center: Technical Support](/help/main-guide/technical-support.md)
* [Adobe Connect Support Blog](https://blogs.connectusers.com/connectsupport/adobe-connect-best-practices/)

## Hardware Requirements

* Computer or laptop with a keyboard and mouse
* 8 GB RAM or more for optimal browser performance
* Second, external monitor is preferred with a minimum resolution of 1280 x 768 pixels
* Internet connection of 100 Mbps or more

## Software Requirements

* Recommended web browsers are Chrome or Firefox
* Able to access **login screen** only, for [Adobe CX Enterprise](https://experience.adobe.com/#/home). Login information will be provided during training
* Have access to a text editor
* Have a program to extract archive (.zip) files
* Have a program to read PDFs such as [Adobe Reader](https://get.adobe.com/reader/)

>[!NOTE]
>
>Do not log in. Please simply test that you can access the link in your browser without your company network blocking it. You may see "your Adobe ID is not linked to your Adobe Experience Cloud solution accounts" message, which is expected. The links are not intended for learners to access anything in advance until you arrive at class. On the first day of class, your instructor will provide the credentials to log in.
